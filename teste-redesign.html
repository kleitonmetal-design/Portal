4️⃣ Checklist de Testes Manuais

Use este checklist para validar o redesign:

🌐 Teste 1: Abrir a página nova
  • Cores visíveis: Clique em paineis-pci.html — verifique que o header, títulos e botões estão em TEAL, não roxo.
🖱️ Teste 2: Interação (Hover)
  • Cards hover: Passe o mouse sobre cada card — deve elevar 8px e mostrar borda top de 6px (teal + laranja gradiente).
  • Botão "Acessar": Hover deve mudar de teal escuro (#1a5f7a) para teal médio (#2d8fa3).
📏 Teste 3: Zoom (ADHD)
  • Zoom 150%: Ctrl/Cmd + "+" três vezes — layout deve manter-se legível, cards devem stackar em coluna.
  • Sem quebra: Nenhum texto deve sair do container ou ficar cortado.
🌙 Teste 4: Modo Escuro
  • Sistema operacional: Ative modo escuro (Settings → Dark Mode) — cores devem permanecer legíveis.
📱 Teste 5: Mobile (768px)
  • Responsive: DevTools (F12) → Toggle device toolbar → 768px — cards devem virar coluna única.
  • Sem scroll horizontal: Página não deve scrollar horizontalmente.
✨ Teste 6: Contraste Visual
  • Legibilidade: Textos em cards brancos (#ecf0f1) devem ser perfeitamente legíveis em cinza escuro (#555555).
  • Destaque: Botões teal devem "saltar" visualmente — eles devem ser o foco do card.
